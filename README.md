# Arithmetic Multiplier Benchmark Suite

This repository contains a comprehensive collection of arithmetic multiplier benchmarks in **AIG (And-Inverter Graph)** format. These benchmarks are designed for evaluating logic synthesis, formal verification, and arithmetic circuit optimization algorithms.

## Dataset Overview

The benchmarks primarily consist of **64x64-bit** multipliers generated using various open-source arithmetic circuit generators. The dataset covers a wide range of architectures by combining different Partial Product Generators (PPG), Partial Product Accumulators (PPA), and Final Stage Adders (FSA).

### Generators Used

* **GenMul**: [https://github.com/amahzoon/genmul](https://github.com/amahzoon/genmul)
* **MultGen**: [https://github.com/temelmertcan/multgen](https://github.com/temelmertcan/multgen)
* **AOKI**: [https://fmv.jku.at/amulet2/](https://fmv.jku.at/amulet2/) (The original AOKI benchmark website is no longer accessible; these files were retrieved from an alternative archive.)

## Directory Structure

The benchmarks are organized by signedness and the tool used for generation:

```text
.
├── signed/
│   ├── genmul/      # Generated by GenMul (Signed)
│   ├── multgen/     # Generated by MultGen (Signed)
│   └── aoki/        # Generated by AOKI (Signed)
└── unsigned/
    ├── genmul/      # Generated by GenMul (Unsigned)
    ├── multgen/     # Generated by MultGen (Unsigned)
    └── aoki/        # Generated by AOKI (Unsigned)

```

## Naming Convention

Each benchmark is named `[PPG]-[PPA]-[FSA].aig`, where PPG, PPA, and FSA denote the partial-product generator, partial-product accumulator, and final-stage adder, respectively. The names of the original AOKI files are preserved; refer to the official AOKI benchmark documentation for their complete architecture definitions.

### GenMul

GenMul benchmarks use `sp` for simple partial-product generation. Their PPA identifiers are:

| Identifier | GenMul architecture |
| --- | --- |
| `ar` | Array |
| `wt` | Wallace tree |
| `dt` | Dadda tree |
| `cwt` | Counter-based Wallace tree |

GenMul calls the last architecture `cwt`; the dataset retains that name rather than treating it as identical to AOKI's `cn` counter tree. The FSA identifiers are:

| Identifier | GenMul architecture |
| --- | --- |
| `rc` | Ripple-carry adder |
| `cl` | Carry-lookahead adder |
| `lf` | Ladner-Fischer adder |
| `ks` | Kogge-Stone adder |
| `bk` | Brent-Kung adder |
| `csf` | Fixed-block carry-skip adder |
| `se` | Serial-prefix adder |

The carry-skip implementation uses a fixed skip-block size, so it follows the AOKI identifier `csf`. In particular, `cs` is reserved for the AOKI carry-select adder.

### MultGen

MultGen's PPG identifiers are `sp`, `bp2`, `bp4`, `bp8`, and `bp16` for simple partial products and Booth encoding with radix 2, 4, 8, and 16. Its PPA identifiers are:

| Identifier | MultGen architecture |
| --- | --- |
| `wt` | Wallace tree |
| `dt` | Dadda tree |
| `ct` | 4:2 compressor tree (`c42` in MultGen) |

The FSA identifiers are:

| Identifier | MultGen architecture |
| --- | --- |
| `rc` | Ripple-carry adder |
| `ks` | Kogge-Stone adder |
| `lf` | Ladner-Fischer adder |
| `hc` | Han-Carlson adder |
| `bk` | Brent-Kung adder |
| `sk` | J. Sklansky conditional adder |


## ⚠️ Known Issues

### GenMul / Signed / Array Multiplier

Due to a specific bug in the **GenMul** tool, the generation of the **Signed Array Multiplier with Carry Skip Adder** fails during the Verilog generation phase.

* **Missing File:** `sp-ar-csf.aig`
* **Location:** `signed/genmul/`

Consequently, the `signed/genmul/` directory contains **27** benchmarks instead of the expected 28. All other combinations were generated successfully.
